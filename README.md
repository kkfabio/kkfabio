## 🎯 Sobre Mim

Desenvolvedor **backend** com foco em **Java** e **Spring Boot**, atualmente estagiário na **ADEERE Comunicações**. Trabalho no desenvolvimento de aplicações web, APIs REST robustas e sistemas de automação de processos, com experiência prática em:

- ✨ Construção de **APIs REST** com Spring Boot
- 🔐 Autenticação e segurança com **Spring Security** e **JWT**
- 📊 Modelagem relacional e otimização de queries SQL
- ⚡ **Otimização de performance** (resultados de até 40% de melhoria)
- 🏗️ Aplicação de **Design Patterns** e **SOLID Principles**

Minha jornada começou com interesse em games e evoluiu para uma carreira focada em desenvolvimento de software de qualidade. Fora do código, estudo sobre arquitetura, performance e boas práticas de desenvolvimento.
